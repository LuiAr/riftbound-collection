# Deck-first redesign

The approved light, game-inspired prototype is now integrated with the existing authenticated application. This change does not migrate data or change account isolation, imports, pricing, billing, or rule validation.

| Before | After |
| --- | --- |
| Collection opens first; builder and saved decks have separate navigation and libraries. | Decks opens first, with one visual saved library. Collection and Activity remain one click away. |
| Saved deck names appear in a compact text list above the editor. | Champion artwork, domain markers, current ownership progress, search, and ownership filters make decks easier to browse. |
| Missing / Review / Edit list / History workspace. | Cards / Improve / Versions / Edit list, with full artwork, missing-only filtering, and persistent save/copy actions. |
| Builder results use thumbnail rows and repeat the saved library. | Full card artwork grouped by deck section; saving refreshes the shared library. Free search leads the creation flow. |
| Switching app sections unmounts editors. | Editors stay mounted, preserving drafts and builder polling. Replacing or discarding a draft asks for confirmation. |
| Four tabs compete for space on phones. | Three bottom navigation items, compact controls, and responsive card grids. |

## Feature map

- **Decks:** create from collection search or paste a list; name, save, edit and delete saved decks; search/filter the library; inspect all matched cards; toggle missing cards; copy complete or missing lists; inspect unmatched lines; show large card details and prices.
- **Improve:** the existing shared analyzer, purchase budget, baseline comparison, draw/role evidence, upgrade swaps, and release scan. Applied changes remain a draft until explicitly saved.
- **Versions:** immutable saved versions, quantity comparisons, and loading an older list as a draft. Legacy decks acquire the existing baseline on their next save.
- **Builder:** champion, owned/purchase mode, SEK budget, free collection search, optional AI generation, fun favourites, temporary copies, retained generation inbox and activity, source/price details, copy and keep. Existing cost limits and provider setup gates remain unchanged.
- **Collection:** search, set and multiple rarity/printing filters; All / Owned / Missing / Need copies; one-of-each and domain/set overview; card prices and foil treatment; CSV import preview/commit and round-trip export.
- **Activity:** compare any two imports, browse read-only historical snapshots, return to the latest inventory. Deck ownership always uses the latest inventory.

The matcher additionally accepts the builder's canonical `main` and `chosen` section headings. A regression test checks that these headings are not treated as unmatched cards and that unknown cards remain surfaced.

## Verification

Performed against an isolated local D1 database and synthetic holdings made from public catalog/reference records. Local fixtures and screenshots are outside the published source; no production holdings, secrets or paid AI requests were used.

- `node --import tsx --test tests/*.test.ts`: 12 passing tests, including the new parser regression.
- `node scripts/test-builder.mjs`: source, strategy, quality, progress, server/billing and background-job suites pass.
- `ADVISER_INVENTORY_PATH=/absolute/synthetic-inventory.json node scripts/test-adviser.mjs`: captured-source adviser replay passes with synthetic holdings, including upgrades, release scans, versions, and authentication checks. This is regression evidence, not a live deck-quality claim.
- `npx tsc --noEmit --incremental false` and the Sites production build pass.
- Browser checks cover saved card art/details, missing-only filtering and copy feedback, draft persistence across navigation, saving versions, historical draft loading, discard confirmation, builder result keep-to-library refresh, collection needs/search, CSV import preview and cancellation, import comparisons and historical read-only browsing. Closing the creation dialog with Escape restores keyboard focus to New deck; no browser console warnings or errors were recorded.
- Responsive checks cover 320, 390, 768 and 1280 px, keyboard focus and reduced-motion styles. The hero uses `overflow: clip` so returning focus to its action cannot scroll the artwork container and clip its heading.

The live rules hub did not satisfy the existing freshness check during QA. Search and upgrades requiring verified current rules therefore remain unavailable; the interface shows the error and the builder disables free search when that rules error is known. Live Cardmarket prices loaded successfully. Completed/failed generation UI was checked with explicitly synthetic records. No paid generation or production deployment was performed.

Unsaved drafts are kept in memory and warn before page unload; they are not restored after a browser restart. Saved data uses the existing account-backed APIs.
